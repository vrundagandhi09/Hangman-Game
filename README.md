# Hangman Game

A simple browser-based Hangman project built with HTML, CSS, and JavaScript.

## Run the game
1. Extract the ZIP file.
2. Open the `hangman_project` folder in VS Code.
3. Open `index.html` in a browser (or use the VS Code Live Server extension).

## How to play
1. Enter a secret word using letters A–Z and select **Start game**.
2. Enter one letter at a time and select **Guess**.
3. You have six incorrect guesses.
4. Guess every letter before the incorrect-guess limit to win.
5. Select **New game** to play another round.

## Features included
- Win and lose messages displayed in the guesses area.
- Guessing is disabled before a word is selected.
- Guessing is disabled after the game ends.
- The guess input clears after each submitted guess.
- Previously guessed letters cannot be submitted again.
